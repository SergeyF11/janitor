# Привратник (Janitor)

**Привратник** — это система удалённого управления ESP-устройствами (реле, выключателями) через веб-интерфейс с поддержкой MQTT (Yandex IoT Core). Система предназначена для организации доступа к устройствам по группам с разграничением прав пользователей, администраторов групп и суперадминистратора.

## Основные возможности

- Управление реле (импульсное/переключатель) через веб-интерфейс.
- Группировка устройств и пользователей.
- Ролевая модель: пользователь, администратор группы, суперадминистратор.
- Аутентификация через логин@топик (локальный логин в группе) или глобальный логин (для суперадмина).
- Интеграция с Yandex IoT Core (автоматическое создание устройств, управление паролями).
- Веб-сокеты для отображения статусов в реальном времени.
- Журналирование событий.
- Автоматический жизненный цикл групп: срок действия, льготный период, блокировка, удаление через 6 месяцев.

## Быстрый старт (для разработки или тестирования)

1. Убедитесь, что установлены Docker и Docker Compose.
2. Склонируйте репозиторий:
   ```bash
   git clone <url-репозитория> janitor
   cd janitor
   ```
3. Создайте файл .env с необходимыми переменными ([см. elfhosted_devops.md](docs/selfhosted_devops.md)).

4. Запустите контейнеры:
    ``` bash 
    docker-compose up -d
    ```
5. Откройте браузер и перейдите по адресу http://localhost:3000/janitor/.

## Технологический стек
Backend: Node.js + Fastify, PostgreSQL, JWT, MQTT, WebSocket.

Frontend: React, Vite.

## Инфраструктура: Docker, Yandex Cloud (IoT Core, Managed PostgreSQL опционально).
