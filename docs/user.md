# Руководство пользователя

## 1. Вход в систему

1. Откройте браузер и перейдите по адресу: `https://ваш-домен/janitor/`.
2. Введите **логин** в формате `имя@топик_группы` (например, `ivan@podjezd1`).
3. Введите **пароль**, выданный администратором.
4. Нажмите кнопку **«Войти»**.

Если вы входите впервые, система может запросить смену пароля.

> **Внимание** Вход по одному логину/паролю возможен только с одного смартфона/компьютера!! 
При необходимости смены смартфона запросите Администратора сброс сессии.
При необходимости управления с нескольких устройств запросите у Администратора ещё один аккаунт.

## 2. Главный экран

После входа отображается список доступных вам групп. Для каждой группы показаны:
- Название группы
- Кнопки управления реле
- Статус устройства (зелёный кружок — онлайн, серый — офлайн)

### Управление реле

- **Импульсное реле** (длительность > 0): кнопка подписана «▶ Название реле».
- **Реле-переключатель** (длительность = 0): кнопка отображает текущее состояние:
  - «○ Название реле — Выкл»
  - «● Название реле — Вкл»

Нажмите на кнопку, чтобы активировать реле.

Если группа заблокирована или истёк срок действия, кнопки становятся неактивными, и отображается баннер с пояснением.

## 3. Профиль и смена пароля

- Нажмите на иконку 👤 в правом верхнем углу.
- В панели профиля отображаются:
  - Ваш логин
  - Отображаемое имя (если задано)
  - Ваш ID (можно скопировать, нажав 📋)
- Кнопка **«Выйти»** завершает сеанс.

Смена пароля выполняется через администратора (или через форму входа, если настроено).

## 4. Выход

Нажмите кнопку **«Выйти»** в панели профиля или в заголовке страницы.

## 5. Установка на мобильные устройства

### Android
    Откройте браузер Chrome.
    Перейдите по адресу приложения (например, https://ваш-домен/janitor/).
    Выполните вход.
    Нажмите на меню (три точки) и выберите «Добавить на главный экран» (или «Установить приложение»).
    При необходимости измените название и нажмите «Добавить».
    На главном экране появится иконка приложения.

### iPhone / iPad (iOS)
    Откройте браузер Safari.
    Перейдите по адресу приложения.
    Выполните вход.
    Нажмите на иконку «Поделиться» (квадрат со стрелкой).
    Выберите «На экран домой» (Add to Home Screen).
    Отредактируйте название (при желании) и нажмите «Добавить».
    Иконка приложения появится на рабочем столе.

### Особенности
    После установки приложение открывается в полноэкранном режиме (без адресной строки).

    Все функции доступны так же, как в веб-версии.

    Для обновления данных перезапустите приложение или потяните список вниз (если поддерживается).
