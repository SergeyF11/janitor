# Подготовка esp к работе

## 1. Оборудование
Для работы в качестве исполнительного устройства подходят любые платы с чипом esp8266/32 и исполнительным(ными) реле на любых пинах.
Есди плата не оснащена встроенным преобразователем USB-UART, то потребуется любой внешний преобразователь с установленным драйвером для вашей операционной системы.

## 2. Скетч
Скетч проверен на esp8266, хотя должен работать и на esp32. Скетч не требует какой либо модификации перед прошивкой, вся настройка осуществляется через captive portal.
Загрузите скетч в IDE Arduino или VS Code Arduino, выберите параметры вашей платы и порт, к которому она подключена. Соберите и прошейте прошивку.

## 3. Настройка
При отсутствии сохранённых настроек при запуске автоматически стартует captive portal с именем JANITOR_XXXXX, где ХХХХХ - индентификатор чипа. 
 - Подключитесь к сети. 
 - Зайдите в captive portal со смартфона или перейдите по адресу http://192.168.4.1
 - Введите настройки сети wifi для подключения. При возможности заполните параметры резервной сети.
 - Выберите пины подключения и наименования для реле. Значение -1 пина означает отсутствие реле. Можно использовать любые пины esp за исключением RX,TX, а также пинов задействованных при загрузке системы (см.документацию к конкретному чипу). Нельзя использовать пин встроенного светодиода esp? поскольку он задействован для визуализации режима работы устройства.
 - Введите сервер и код привязки (код можно получить на странице настройки группы администратора).
 - Сертификат ( не реализовано ). Загрузите файл сертификата для https для сервера или корневого сертификата CA.
 - Перейдите на страницу Инфо, проверьте настройки и нажмите кнопку Завершить, для перезагрузки устройства в рабочий режим.

 > **⚠️ Внимание!** Для входа в Настройки (captive portal) на настроенном устройстве, перегрузите его при замкнутом пине RX на землю.

## 4. Работа
При загрузке устройство ищет сеть WiFi индицируя поиск частым миганием встроенного светодиода (при наличии).
Поле подключения к сети выполняется синхронизация времени с NTP-серверами, привязка устройства к серверу (если ещё не привязано) и подключение к реестру mqtt Яндекс Core IoT. 

Неудача индицируется очень частым миганием светодиода. В этом случае зайдите в настройки повторно и тщательно проверьте все параметры подключения.

При входе в нормальный режим работы светодиод будет кратковременно вспыхивать 1 раз в секунду и появится индикация подключения на странице Устройство Администратора группы. На вкладке Реле Администратор может настроить параметры имульса реле ( при значении 0 реле перейдёт в режим вкл/выкл по команде !). 

Наименования реле загружаются на сервер только при регистрации устройства! Если вы хотите сменить нименования, зайдите в настройки в портале, а затем  выполните привязку устройства к группе.
