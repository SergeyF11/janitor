# Руководство администратора группы

## 1. Вход

Вход выполняется так же, как и для обычного пользователя: `логин@топик_группы`.  
После входа на карточках групп, где вы являетесь администратором, появляется кнопка ⚙️.

## 2. Управление пользователями группы

Нажмите ⚙️ на нужной группе, затем перейдите на вкладку **«Пользователи»**.

### Добавление нового пользователя
- Нажмите **«+ Добавить»**.
- Выберите режим **«Новый»**.
- Заполните:
  - **Логин** (уникальный в группе)
  - **Пароль** (мин. 6 символов)
  - **Роль** (Пользователь / Администратор)
  - **Описание** (необязательно)
- Нажмите **«Добавить»**.

### Добавление существующего пользователя по ID
- Нажмите **«+ Добавить»**.
- Выберите режим **«По ID»**.
- Введите **ID пользователя**.
- Укажите **Описание** (необязательно).
- Нажмите **«Добавить»**.

### Редактирование описания
- В списке пользователей нажмите ✎ рядом с описанием.
- Измените текст и сохраните.

### Сброс пароля пользователя
- В карточке пользователя введите новый пароль в поле **«Новый пароль»**.
- Нажмите кнопку 🔑.

### Удаление пользователя из группы
- Нажмите кнопку **«🗑 Удалить»** (нельзя удалить самого себя).  
  Если после удаления у пользователя не останется других групп, он будет полностью удалён из системы.

## 3. Управление устройством (ESP)

> **Внимание!**  
 Прежде чем продолжить, прошейте esp как указано в [Подготовка esp к работе](./esp_firmware.md)

Перейдите на вкладку **«Устройство»**.

### Генерация кода привязки
- Нажмите **«Сгенерировать код привязки»**.
- Отобразится 6-значный код и срок его действия.
- Настройте ESP и введите этот код на устройстве  (через Captive Portal).

### Просмотр статуса
На вкладке отображаются:
- ID устройства
- Версия прошивки
- Статус онлайн/офлайн
- Время последнего подключения

## 4. Настройка реле

Перейдите на вкладку **«Реле»**.
- Для каждого реле показаны название, тип (импульсное/переключатель) и текущее состояние.
- Чтобы изменить название или длительность импульса, нажмите ✎, отредактируйте и сохраните.
- Можно вручную активировать реле кнопкой.

## 5. Журнал событий

На вкладке **«Журнал»** отображаются события группы: включения реле, добавление/удаление пользователей, изменения статуса группы.
