# Руководство суперадминистратора

## 1. Вход

Суперадминистратор входит по отдельному URL:  
`https://ваш-домен/janitor/superadmin/`  
Используется глобальный логин (без @), например, `superadmin`, и пароль, заданный при установке.

## 2. Панель управления

После входа доступны вкладки:
- Статистика
- Администраторы
- Группы
- Пользователи
- Устройства
- Журнал
- SQL

## 3. Управление администраторами

На вкладке **«Администраторы»**:
- **Создать администратора**: укажите логин (уникальный в группе регистрации), пароль, выберите группу, задайте описание (необязательно) и флаг «Одна сессия».
- В списке администраторов отображается логин с суффиксом `@топик_группы`, список групп с описаниями, флаги.
- Действия: переключение режима одной сессии, блокировка/разблокировка, сброс сессий, смена пароля, удаление.

## 4. Управление группами

На вкладке **«Группы»**:
- **Создать группу**: название, MQTT топик (генерируется автоматически), квота пользователей. При создании автоматически создаётся администратор с логином `admin@топик` (пароль показывается в модальном окне).
- В списке групп отображаются: название, топик, статус, срок действия (с редактированием), квота (редактируемая), количество пользователей и администраторов.
- **Редактирование имени**: клик по ✏️.
- **Редактирование срока**: клик по ✏️ рядом со сроком. Открывается календарь (только дата). Грейс-период (+30 дней) устанавливается автоматически.
- **Редактирование квоты**: клик по ✏️ рядом с квотой.
- **Назначение администратора**: выберите администратора из выпадающего списка и нажмите «+ Назначить».
- **Блокировка/разблокировка**: кнопка «Блок» / «Разблок».
- **Удаление группы**: кнопка ✕. При удалении каскадно удаляются устройства, реле, токены, а пользователи, состоящие только в этой группе, удаляются полностью.

**Фильтрация групп**: доступны фильтры по статусу: все, активные, в льготном периоде (жёлтая подсветка), заблокированные (красная подсветка).

## 5. Управление пользователями (глобальный просмотр)

На вкладке **«Пользователи»**:
- Отображаются все пользователи с возможностью фильтрации по роли, группе и поиску.
- Для каждого показан логин (с суффиксом `@топик_регистрации`), роль, статус, количество групп.
- Действия: блокировка/разблокировка, сброс сессий.

## 6. Устройства

На вкладке **«Устройства»**:
- Список всех зарегистрированных ESP-устройств: группа, статус онлайн, версия прошивки, время последнего контакта.
- Кнопка ✕ для удаления устройства (также удаляется из Yandex Cloud).

## 7. Журнал событий

Глобальный журнал всех событий с фильтрацией по действию, группе, дате. Системные события (grace-период, блокировка, удаление данных) помечены специальными иконками.

На вкладке **«SQL»** можно выполнять SELECT-запросы к базе данных (операции изменения запрещены). Результат отображается в виде таблицы.
